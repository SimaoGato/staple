# EPIC-12 — Pro features (Phase 2)

**Goal.** Give Pro real value beyond removing the caps, using features that were never free: page-level editing, adding passwords to PDFs, and HEIC (iPhone photo) input. Because these are new, launching Pro takes nothing away from free users.

## In scope
- Page-level edit: rotate, reorder and delete pages, using thumbnails.
- Add a password to output PDFs.
- HEIC input for the image tools and images-to-PDF. Check codec size and licensing first.

## Out of scope
- Mobile browsers and more languages (Phase 3, not yet broken into epics).

## Depends on
- EPIC-06, EPIC-07, EPIC-11

## Done signals
- Each feature works for Pro users and shows an upgrade prompt to free users.
- A HEIC licensing note is recorded in `docs/`.

## Candidate stories
- Page-level edit: rotate, reorder, delete
- Add password to output PDF
- Spike: HEIC codec size and licensing
- HEIC input
